# agroSystem

Веб-приложение для автоматизации управления поливом в теплице. Система собирает показания датчиков, принимает решения о поливе на основе заданных условий и ведёт журнал событий.

## Стек технологий

- Node.js
- Express
- PostgreSQL
- Sequelize (ORM)

## Структура базы данных

База данных `watering` состоит из 12 таблиц:

| Таблица | Назначение |
|---|---|
| `пользователи` | Логины и хэши паролей |
| `список_блока_теплиц` | Теплицы и блоки |
| `клапаны` | Исполнительные механизмы |
| `теплицы_клапаны` | Связь теплиц и клапанов |
| `ежедневные_условия` | Показания датчиков за день |
| `добавки` | Удобрения, кислоты и щёлочи |
| `история_раствора` | Приготовленные замесы |
| `состав_раствора` | Состав каждого замеса |
| `история_поливов` | Записи о поливах |
| `история_дренажа` | Записи о дренаже |
| `баки` | Баки с водой или раствором |
| `назначение_баков` | Типы баков |

### Связи между таблицами

```text
список_блока_теплиц -- теплицы_клапаны -- клапаны
                                            |
                                            +-- ежедневные_условия
                                            |
                                            +-- история_поливов -- история_дренажа
                                                     |
                                                     +-- история_раствора -- состав_раствора -- добавки
                                                     |
                                                     +-- баки -- назначение_баков
```

## Установка и запуск

### Требования

- Node.js версии 18 или выше
- PostgreSQL версии 14 или выше
- npm
- Python

### 1. Клонирование репозитория

```bash
git clone <url>
cd agroSystem
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Создание базы данных

```bash
psql -U postgres -c "CREATE DATABASE watering;"
```

Применение SQL-схемы:

```bash
psql -U postgres -d watering -f schema.sql
```

### 4. Настройка файла `.env`

Создайте файл `.env` в корне проекта:

```env
PORT=5000

DB_NAME=watering
DB_USERNAME=app_user
DB_PASSWORD=AppPassword123!
DB_HOST=172.25.25.97
DB_PORT=5432

NODE_ENV=development
```

### 5. Запуск сервера

```bash
npm run dev
```

Сервер запустится по адресу:

```text
http://localhost:5000
```

## Генератор данных ежедневных условий

Генератор создаёт тестовые показания датчиков за день.

### Запуск

```bash
python generator.py
```

Генератор предложит выбрать сценарий:

- Лето
- Осень / Весна
- Тестовый режим

### Генерируемые параметры

| Параметр | Диапазон |
|---|---|
| Температура | +15...+35 °C |
| Влажность | 50...80 % |
| EC | 1.8...2.8 мСм/см |
| pH | 5.8...6.5 |
| Погода | солнечно, облачно, дождь |

## Генератор дренажа

Генератор создаёт по одной записи дренажа на каждый полив.

### Запуск

```bash
python generator_drainage.py
```

## Логика полива

1. Получить текущие показания датчиков.
2. Сравнить показания с пороговыми значениями.
3. Если условия выполнены, включить полив.
4. Записать событие в журнал.

## Расчёт дренажа

Дренаж рассчитывается по формуле:

```text
Дренаж (%) = (Объём дренажа / Объём полива) × 100
```

Идеальный диапазон:

```text
0–3%
```
