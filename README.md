# AgroSystem

Веб-приложение для автоматизации полива в теплице.
Система имитирует работу реального растворного узла: собирает показания
датчиков, управляет временем начала и окончания полива и ведёт журнал событий.

---

## Возможности

- Аутентификация пользователей
- Учёт теплиц, клапанов и баков
- Сбор показаний датчиков (температура, погода, влажность, EC, pH)
- Автоматическое принятие решения о поливе
- Управление пользователем временем полива по клапанам
- Приготовление растворов с автоматическим списанием добавок
- История поливов и дренажа
- Журнал событий
- Графики и отчёты

---

## Сущности

**Оборудование**
- Теплицы — блоки с описанием (что растёт, примечания)
- Клапаны — производитель, модель, тип, диаметр, состояние
- Баки — назначение (чистая вода, питательный раствор, дренаж)

**Агрономия**
- Ежедневные условия — показания датчиков за день
- Добавки — удобрения, кислоты, щёлочи с учётом остатка
- Растворы — приготовленные замесы
- Состав раствора — какие добавки и в каком количестве вошли в замес

**События**
- История поливов — время, длительность, объём воды, использованный раствор
- История дренажа — сколько воды вышло обратно

**Доступ**
- Пользователи — логины и хэши паролей

**Связи**
- Одна теплица может иметь несколько клапанов

---

## Как это работает

1. Генератор создаёт показания датчиков с учётом сезона (лето / демисезон)
2. Данные сохраняются в базу
3. На основе условий принимается решение о поливе
4. При создании раствора автоматически списываются добавки со склада
5. Все события записываются в журнал
